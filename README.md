## 2. Информация о системе

### Команда `whoami`

```text
[root]
```

Назначение: определяет имя текущего пользователя.

### Команда `pwd`

```text
[/home/bard]
```

Назначение: показывает путь к текущему рабочему каталогу.

### Команда `uname -a`

```text
[/]
```

Назначение: выводит сведения о ядре и системе.

### Команда `lsb_release -a`

```text
[$ lsb_release -a
No LSB modules are available.
Distributor ID: Ubuntu
Description:    Ubuntu 24.04 LTS
Release:        24.04
Codename:       noble
]
```

Назначение: показывает информацию о дистрибутиве Linux. Если команда недоступна, указать результат `cat /etc/os-release`.

## 3. Создание каталога и файла

Создан каталог `~/os-course/pr01` с помощью команды:

```bash

```

Для перехода в каталог использована команда:

